# Recipe Format

A recipe is a markdown file under `recipes/<category>/<name>.md`:
YAML-ish frontmatter + one ```csharp block.

```
---
name: vrc_physbone_audit          # find_recipe exact-match key
old_tool: vrc_physbone_audit      # legacy tool name (same unless renamed)
request_type: vrcPhysBoneAudit    # legacy wire name (provenance)
description: "..."                # searched (weight x2)
category: vrchat-avatar           # directory + resource uri segment
tags: [vrchat, physbone, audit]   # searched (weight x3)
params:
  - {name: avatarPath, type: string, required: true, desc: "..."}
kind: recipe | redirect | doc     # redirect = "use new tool X"; doc = guidance only
sync: sync | job                  # job = run via execute_editor_command {run_as_job:true}
requires: []                      # ["vrcsdk"] = needs VRC SDK in the project
qa: clean | review                # review = extracted heuristically, verify on first use
source: VRCAuditHandler.cs#HandlePhysBoneAudit
---
```csharp
// body: C# statements. Inputs arrive as JObject `args`.
// Must end with `return <object>;`.
```
```

## Execution contract

The body is pasted into `execute_editor_command` wrapped as:

```csharp
class EditorCommand {
    static object Execute() {
        var args = Newtonsoft.Json.Linq.JObject.Parse("<caller-provided json>");
        // ...recipe body...
    }
}
```

(In practice the model adapts the body freely — the frontmatter `params`
say what `args` expects. `// requires-using:` hints at the top of a body
list namespaces to add as `using` directives.)

## Index

`recipes/_index.json` is the only file the server loads at boot:
`[{name, category, tags, description, kind, sync, requires, qa, path, sha1}]`.
It is generated by a deterministic extraction pipeline in the development
repository; treat it as read-only metadata alongside the recipe files.

## find_recipe behavior

1. Exact `name` match (case-insensitive) → that recipe's full body, alone.
2. Otherwise token scoring: name x3, tags x3, description x2; all-tokens-hit
   boost; top-N full bodies (`names_only` for just the ranked list).

Recipes are also MCP resources: `recipe://<category>/<name>`.
